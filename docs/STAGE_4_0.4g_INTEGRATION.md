## Объём

Итоговая проверка принятой системы 0.4a–0.4f, без расширения гармонического
каталога. Добавлен Stage4IntegrationTests: готовые события ARA → timeline/window
→ анализ гармонии/источников → объяснение/relative preference keys → tension
filter/selection → viewer → проверка фразы и желаемой кривой.

В 12 тональностях проверяются контекст Em7–A7b13–D7 в C major и его переносы,
предполагаемая минорная цель, реальные соседние аккорды, отсутствие автоматической
метки полного harmonic minor/уменьшённого арпеджио, одна основа вне фильтра,
снятие назначения и отказ от скрытого выбранного материала. F над A7b13 и F#
как реальная терция D7 допустимы; F как объявленная терция D7 отклоняется даже
при совпавшей желаемой кривой. Предполагаемый Dm не подменяет фактический D7.

Позиции seek и признаки PLAY/STOP проверяются на уровне host-neutral snapshot.
Отсутствующий контекст не сохраняет прежний каталог. Тест не управляет Studio Pro
и не выдаётся за визуальную/транспортную приёмку реального хоста.

В scalar phrase diagnostic уточнено объяснение неоценённого tension: неизвестным
может быть лишь часть профиля, поэтому целый запрошенный уровень не подтверждён.
Гармонические правила, ноты, фильтр, shared persistence и host state не изменены.

Общая документация приведена к принятой политике ручных меток, базы вне фильтра,
независимых описания/желаемой кривой и новой декомпозиции 0.4a–0.4g.
Исторические 0.4c fix1–fix5 и 0.4d–0.4f остаются принятыми.

## Автоматические gates

Всего 27 наборов: 26 прежних и Stage4IntegrationTests. Обязательны:

- context mapper/window/recognizer/global-local-modal ambiguity и explanation;
- major/minor, secondary/SubV, Corcovado-family, ii/iiø, presumed/actual goals;
- фиксы 0.4c и специальные источники, опорные/характерные/целевые ноты;

  view projection, enharmonic spelling и geometry;
- PhraseMatcher, описательный профиль и кривая, неизменность нот/ритма;
- JUCE SharedTensionsTests: реальные файлы/несколько экземпляров/процессов,
  V5 host roundtrip, миграция V2/V3/V4, снятые метки, stale project import,
  сохранение между проектами/перезапуском, malformed/future/write-failure данные.

Проверен processor wiring: host state импортирует только отсутствующие общие
метки, затем читает актуальный shared profile; желаемый фильтр/режим грифа остаются
настройками экземпляра. Белый маркер сравнивает pitch class с корнем реального
текущего аккорда. Перерисовка реального UI остаётся живым gate.

## Итоговый чек-лист Studio Pro

1. Установить Windows VST3 0.4g, открыть Corcovado и убедиться в подписи версии.
2. База одна, сверху и без назначаемого tension. Список способов не дублируется;
   источники, характерные ноты и цель соответствуют принятой гармонической базе.
   В A7b13 используется D harmonic minor; Bb dim7 доступен. D7 остаётся реальным
   следующим аккордом, не становится временным центром оборота.
3. Переключить Все/T1/T2/T3; назначить, изменить и снять метку. Пустой уровень
   поясняется; скрытый источник не остаётся активным. База остаётся доступной.
4. Выбрать источники с другим корнем; белым отмечен основной тон текущего аккорда.
   Проверить буквы/ступени, слои и диапазон грифа. Двойные бемоли dim7 сохраняются.
5. Seek в обе стороны, PLAY/STOP, смена аккордов: список, объяснение, стан и гриф
   согласованы с текущей позицией. При отсутствии аккорда нет старой подсказки.
6. Сохранить и повторно открыть проект: фильтр, режим грифа, размер окна и метки
   восстановлены. Открыть другой проект: общие метки доступны, его фильтр независим.
7. После изменения/снятия метки открыть ранее сохранённый проект: актуальное
   назначение не откатывается, снятая метка не возвращается. При доступности
   проверить проект прежней версии; автоматическая V2/V3/V4 миграция обязательна.
8. Контрольный major ii–V–I и minor iiø–V–i: источники и разрешения соответствуют
   модели. Нет новых кракозябр, сломанных элементов или изменений назначения нот.

Фразы и кривая проверяются автоматическими контрактами; редактор/библиотека ещё
отсутствуют. Приёмка доступного поведения не утверждает реализацию этих будущих UI.
