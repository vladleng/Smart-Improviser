# Stage 3 / 0.3e-ui — структурная разгрузка интерфейса

`0.3e-ui` — отдельный UI-checkpoint поверх музыкальной логики 0.3e и русификации fix2. Цель — сделать live-тесты следующих подэтапов удобными, не превращая текущий диагностический editor в финальный продуктовый дизайн.

## Что меняется

- Верхняя карточка **«Текущий контекст»** остаётся видимой всегда и теперь показывает не только аккорд/тональность, но и:
  - текущую гармоническую функцию;
  - распознанный гармонический оборот и роль аккорда в нём;
  - краткую логику мышления для импровизации: доступные scale/m6-подходы и подтверждённое голосоведение в следующий аккорд.
- Названия функций в UI сделаны компактными: **Тоника / Субдоминанта / Доминанта / SubV**. Слово «функция» в самом значении не дублируется.
- Большой прежний экран «всё сразу» заменён на четыре переключаемых/сворачиваемых раздела:
  1. **Материал** — открыт по умолчанию; harmonic concepts и практические идеи для импровизации.
  2. **Источники / ноты** — гаммы, m6-thinking, chord anchors, guide tones, characteristic tones, targets и resolution moves.
  3. **Гармонический анализ** — global/local function, pattern, interpretation, confidence и candidates.
  4. **ARA / диагностика** — binding, host access, transport, PPQ, события и revisions.
- В каждый момент открыт один раздел; остальные отображаются как закрытые спойлеры. Это сохраняет компактную высоту окна и не требует внешнего скролла всей формы.
- Длинный контент каждого раздела прокручивается внутри собственной области.
- Музыкальная логика Core, Harmonic Engine, Improvisation Engine, rule IDs и результаты анализа не меняются.

## Логика строки «Мышление»

Это краткий summary уже существующих данных Stage 3, а не новый музыкальный анализ:

- для обычного диатонического источника показывается название доступного лада;
- если стратегия имеет thinking structure, в summary показывается её аккордовая форма (например `Dm6`, `Abm6`);
- если Stage 2 подтвердил разрешение, добавляются реальные голосоведческие движения (например `B->C`, `F->E`) и целевой аккорд;
- если scalar source недоступен, остаётся базовая логика «звуки аккорда + направляющие тоны».

Таким образом верхняя карточка отвечает на три практических вопроса: **что сейчас звучит, какой это оборот и как обыгрывать этот аккорд в данном контексте**.

## Что пока сознательно не делаем

- финальный визуальный стиль;
- Tension UI / T1–T3 controls;
- production-level карточки, иконки и анимации;
- пользовательские настройки layout;
- нотный/табулатурный editor.

Эти решения логичнее принимать после появления Tension Engine. Сейчас фиксируется только информационная архитектура экрана.
