# 0.5f — первый общий набор

Шесть собственных коротких примеров, revision 1, tag `common-mvp`.
Они создаются при запуске плагина, без импорта и без записи common originals в user archive.
IDs: `common:mvp.{major|minor}.{anchors|guides|approach}`.

| Оборот в примере | Concept | Ноты по аккордам (C4 = MIDI 60) |
|---|---|---|
| Dm7–G7–Cmaj7 | concept.chord-anchors | D4 F4 A4 C5 / B3 D4 F4 D4 / E4 G4 B4 G4 |
| Dm7–G7–Cmaj7 | concept.guide-targeting | F4 C4 / F4 B3 / E4 |
| Dm7–G7–Cmaj7 | concept.chromatic-approach-below + anchors | D4 F4 A4 C5 / B3 D4 F4, пауза, D#4 / E4 |
| Dm7b5–G7–Cm7 | concept.chord-anchors | D4 F4 Ab4 C5 / B3 D4 F4 D4 / Eb4 G4 Bb4 G4 |
| Dm7b5–G7–Cm7 | concept.guide-targeting | F4 C4 / F4 B3 / Eb4 |
| Dm7b5–G7–Cm7 | concept.chromatic-approach-below + anchors | D4 F4 Ab4 C5 / B3 D4 F4, пауза, D4 / Eb4 |

Каждый аккорд занимает 4 beats. Опоры — четверти; guide-line — 2+2 / 2+2 / 4.
В подходе: четверти на ii, три четверти на V, пауза 0.5, подход на 7.5 длиной 0.5,
цель на 8 длиной 4. Корни регистров D4=62, G3=55, C4=60; octave offsets сохраняются явно.
Цель — терция тоники, роли подхода и полная группа связывают подготовку с реальным следующим аккордом.
Третья/септима — `guideTone`, опоры — `chordAnchor`, приземление — `resolutionTarget`.
Не используется автоматически выбранный source rule. Concepts ссылаются на принятый движок;
точный гармонический оборот и качества всех трёх аккордов обязательны.

## Оценка и независимость

Начальная tension не назначена: All допускает гармонически подходящие фразы,
T1/T2/T3 и заданная кривая исключают их до ручной оценки.
Влад оценивает материал. В библиотеке выберите общий пример → «Личная копия»,
задайте T1/T2/T3 и нажмите «Сохранить». Оценка хранится в своей копии;
общее назначение уровня способов обыгрывания Stage 4 остаётся отдельным профилем.
Common original неизменяемый; копия/вариант получают собственный ID и parent revision 1.
Профиль по сегментам, если присутствует у другой фразы, сохраняется: простой selector его не заменяет.

## Studio Pro checklist

1. Установить VST3 0.5f. Открыть «Библиотека» → «Общая библиотека»: шесть примеров.
   Проверить относительные ноты, octave offsets, начало/длины, корни MIDI и цели;
   source/author/license показаны в текстовом блоке. Пояснение можно читать в подборе.
2. Поставить Dm7, G7, Cmaj7, Fmaj7 на 0, 4, 8, 12 beats; курсор точно на начало Dm7.
   В «Подбор фраз» выбрать All и tag `common-mvp`: три подходящих major записи.
   Последний аккорд нужен как известная правая граница тоники.
3. Заменить на Dm7b5, G7, Cm7, Fm7: три minor записи. У major — объяснение отказа.
   Из середины аккорда 12-beat пример может не поместиться — это явное timing mismatch.
4. Без ручной оценки выбрать T1/T2/T3: common примеры не подходят из-за неизвестной tension.
5. Сделать личную копию, назначить T2, сохранить. В подборе T2 подходит эта копия
   при верном обороте. Общий оригинал остаётся без оценки. Снять оценку и сохранить — снова только All.
6. Создать вариант, изменить имя/пояснение; перезапустить DAW: копии, оценка, ноты,
   регистр и lineage сохранены, общие шесть примеров доступны без импорта.
7. Оценить музыкальные последовательности на инструменте и сообщить, какие уровни
   следует принять для исходного набора, если нужна общая классификация.

Это библиотечный просмотр и подбор. Транспозиция — Stage 6, полный viewer размещённой
фразы и Song workspace — Stage 7, нотный/TAB редактор — Stage 8.
