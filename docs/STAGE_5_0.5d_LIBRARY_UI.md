# 0.5d — Library UI

База: 0.5c принята Владом; PR #61 merged cf86772. Stable остаётся 0.5.
Согласованный ввод: название, текст идеи, необязательные музыкальные поля.

Кнопка «Библиотека» открывает отдельное окно, не заменяя основной контекст/гриф.
Слева common/user записи; справа название, текст, ритм/гармония, пояснение и таблица нот.
Ступени 1..13 с b/#; октавное смещение -11..10; начало >=0, длительность >0 в beats (десятичная точка);
Номер аккорда от 1 (в модели chordIndex от 0). Пустые поля остаются неизвестными. Это не MIDI-нота: референс корня не угадывается.
Название и tagging не обязательны. Музыкальная последовательность сохраняется как Idea, без автоматического превращения в готовую Phrase или назначения T1.

Доступны новая идея, сохранение, независимая личная копия и вариант с точной lineage.
Common доступна для чтения; первый распространяемый набор появится в 0.5f.
У Phrase доступны название/пояснение и просмотр нот; семантические поля, sources, roles,
targets, evidence, регистр, tension и provenance сохраняются без изменений.
Полный редактор готовой Phrase — Stage 8.

Сохранение сначала проверяет отдельную копию состояния, затем фиксирует файл с ожидаемым stamp.
Только после успешной записи меняется состояние процессора. Ошибки/конфликты оставляют форму
и старую библиотеку. Черновик блокирует переключение записи/domain и обновление; явно сохранить
или отменить. При конфликте скопировать нужный текст, отменить правки, обновить и применить снова.
Закрытие окна библиотеки скрывает его, сохраняя форму до закрытия основного редактора плагина.
Перед закрытием основного редактора несохранённые правки следует сохранить.
Файлы не читаются на таймере или audio callback, библиотека не входит в DAW state.
